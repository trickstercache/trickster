# Changelog

All notable changes to Trickster 2.x are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Each minor release also has a narrative overview in `docs/new-changed-<version>.md`.

## [Unreleased]

### Added

- Any value in a configuration file can reference an environment variable, whatever its type, with `${NAME}`, `${NAME:-default}` or `${NAME:?message}`. A value that is only a reference to an unset variable leaves the setting at its default. See [Environment Variable References](./docs/configuring.md#environment-variable-references).

### Changed

- A literal `${` in a configuration value now needs to be written `$${`. Inside `request_rewriters` instructions, only `TRK_`-prefixed variables are expanded, so capture tokens like `${1}` and `${site}` are unchanged.
- The config view shows `<secret>` instead of `*****` for a Redis `password` and the Graphite `origin_password` and `origin_authorization`.

### Fixed

- `${VAR}` references were never expanded, even in the fields documented to support them, such as a Redis `password` or authenticator `users`.
- The config view showed a user router's `to_credential`, discovery `password`, `bearer_token` and headers, tracing headers and credential-named `request_params` in plain text.

## [2.2.0] - 2026-10-26

See [What's New in Trickster 2.2](./docs/new-changed-2.2.md) for an overview.

### Added

- Layer 4 (TCP and UDP) load balancing on stream listeners, with new `race` and `mirror` mechanisms. See [Load Balancing Stream Listeners](./docs/alb.md#load-balancing-stream-listeners).
- Configurable sticky sessions for the load balancer. See [Sticky Sessions](./docs/alb.md#sticky-sessions).
- Delta proxy cache acceleration for TimescaleDB, and a `SELECT` result cache for any Postgres-compatible database. See [PostgreSQL and TimescaleDB](./docs/postgres.md).
- GreptimeDB backend provider (SQL and PromQL). See [GreptimeDB](./docs/greptimedb.md).
- QuestDB backend provider. See [QuestDB](./docs/questdb.md).
- VictoriaMetrics backend provider for the MetricsQL and Graphite HTTP endpoints. See [VictoriaMetrics](./docs/victoriametrics.md).
- AWS CloudWatch Metrics acceleration on the PromQL endpoints. See [Amazon CloudWatch PromQL](./docs/aws.md#amazon-cloudwatch-promql).
- TSM Global Evaluation: a Time Series Merge ALB can evaluate each PromQL query once over the raw series of every member, through Prometheus remote read (`mimir` flavor) or the Thanos StoreAPI (`thanos` flavor), with raw series delta-cached. See [Global Evaluation](./docs/alb.md#global-evaluation).
- Media over QUIC (MoQ) Transport caching relay for drafts -17 through -22, over native QUIC and WebTransport. See [Media over QUIC](./docs/moq.md).
- HTTP/3 and WebTransport on HTTPS listeners generated by the Kubernetes controller. See [GatewayClass parameters](./docs/kubernetes-gateway.md#gatewayclass-parameters).
- HTTP `QUERY` method ([RFC 10008](https://www.rfc-editor.org/rfc/rfc10008.html)), cached and keyed on the request body. See [The QUERY Method](./docs/paths.md#the-query-method).
- Automatic certificates from Let's Encrypt or any other ACME certificate authority. See [Automatic Certificates](./docs/acme.md).
- Origin resolution via DNS SRV records, with failover across targets and tiers. See [Origin Resolution via DNS SRV](./docs/origin-resolution.md).
- Static file server backend provider. See [Static File Server Backend](./docs/static.md).
- Step alignment modes, chosen per backend with the `step_alignment` option. See [Step Alignment](./docs/step-alignment.md).
- `idle_timeout`, `read_timeout` and `max_header_bytes` listener options. See [Connection Timeouts and Header Size](./docs/configuring.md#connection-timeouts-and-header-size).
- Rate limiting of requests, connections, sessions or datagrams at the listener, backend and path. See [Rate Limiting](./docs/rate-limiting.md).
- IP access control lists at the listener, backend and path, with the most specific winning. See [IP Access Lists](./docs/ip-acl.md).
- Geo ACLs, using MaxMind databases, RFC 8805 geofeeds or headers from trusted downstreams. See [Geo ACLs](./docs/geo-acl.md).

### Changed

- **Breaking:** the `Forwarded`, `X-Forwarded-*` and `X-Real-IP` values a request arrives with are forwarded only when one of the listener's `trusted_proxies` delivered it. A listener behind a load balancer must list it in `trusted_proxies` for origins to keep seeing client addresses. See [Forwarding Headers to the Origin](./docs/configuring.md#forwarding-headers-to-the-origin).
- Renamed backend options `backfill_tolerance` to `volatile_window`, `backfill_tolerance_points` to `volatile_window_points`, and `fastforward_ttl` to `partial_bucket_ttl`. The former keys are still accepted. See [Renamed Backend Options](./docs/configuring.md#renamed-backend-options).
- HTTP listeners close keep-alive connections that wait more than 2 minutes for their next request; idle connections were previously never closed.
- The Filesystem and bbolt caches are rebuilt for large caches and large objects. See [Disk Caches](./docs/caches.md#disk-caches).
- Time series merging counts label sets returned by several members once for `count` or `group` over an inner `count` or `group`.
- All backend providers decode origin responses as a stream, and heap allocations are reduced across the request path.

### Security

- HTTP listeners remove `.` and `..` path segments before routing, closing a bypass of path-scoped controls such as `authenticator_name: none`. See [Path Normalization](./docs/configuring.md#path-normalization).
- Fixed several authenticator defects ([#1180](https://github.com/trickstercache/trickster/pull/1180)).
- Hardened listener and proxy request handling ([#1184](https://github.com/trickstercache/trickster/pull/1184)).

### Fixed

- `use_cache_chunking: true` is honored from configuration again; since 2.0 it was silently reset to `false` at load. Chunked byterange caching no longer zeroes chunks on a partial hit, serves evicted chunks as zeros, or truncates bodies under concurrent reads. See [Chunked Caching](./docs/chunked_caching.md).
- A reload that removes or drains an HTTP/3 endpoint releases its UDP port. See [HTTP/3 Reloads](./docs/http3.md#reloads).
- `log_level`, `TRK_LOG_LEVEL` and `-log-level` accept level names in any case. See [Environment Variables](./docs/configuring.md#environment-variables).
- A rule's `url`, `url_no_params`, `scheme`, `host`, `hostname` and `port` inputs, and a request rewriter's host instructions, act on the URL the client requested. See [input_source permitted values](./docs/rule.md#input_source-permitted-values).
- The delta proxy cache recovers from a time series cache entry that fails to unmarshal ([#1213](https://github.com/trickstercache/trickster/pull/1213)).
- TSM no longer unmarshals non-2xx gather responses as time series ([#1212](https://github.com/trickstercache/trickster/pull/1212)).
- Fixed a data race in file watching on kqueue platforms (macOS, BSD) ([#1217](https://github.com/trickstercache/trickster/pull/1217)).

## [2.1.0] - 2026-09-21

See [What's New in Trickster 2.1](./docs/new-changed-2.1.md) for an overview.

### Added

- Kubernetes Gateway API and Ingress controller, enabled with the top-level `kubernetes` section. See [Kubernetes Gateway](./docs/kubernetes-gateway.md), [Kubernetes Ingress](./docs/kubernetes-ingress.md), [RBAC](./docs/kubernetes-rbac.md) and [Deployment](./docs/kubernetes-deploy.md).
- TricksterCachePolicy custom resource for attaching caching behavior to Gateways, HTTPRoutes, Ingresses and Services. See [TricksterCachePolicy](./docs/kubernetes-cache-policy.md).
- ALB pool member auto-discovery via Kubernetes APIs, DNS A and SRV records, and more. See [ALB Auto-discovery](./docs/alb-autodiscovery.md).
- Regex path matching, with capture groups exposed to request rewriters. See [Regex Paths](./docs/paths.md#regex-paths).
- Wildcard host routing with single-label (`*.example.com`) and any-depth (`**.example.com`) wildcards. See [Host Resolution](./docs/paths.md#host-resolution).
- InfluxDB 3.x acceleration, including over Flight SQL (gRPC). See [InfluxDB 3.x Support](./docs/influxdb.md#influxdb-3x-support).
- Caching of InfluxDB Prometheus remote reads ([#1102](https://github.com/trickstercache/trickster/pull/1102)).
- ClickHouse native (TCP/binary) protocol support in either direction. See [Native Binary Protocol Support](./docs/clickhouse.md#native-binary-protocol-support).
- Graphite backend provider. See [Graphite](./docs/graphite.md).
- Apache Druid backend provider. See [Apache Druid](./docs/druid.md).
- MySQL backend provider for time series-like queries. See [MySQL](./docs/mysql.md).
- HTTP/2 cleartext (h2c) on listeners, HTTP/2 to `https://` origins via ALPN, the `h2c_prior_knowledge` backend option, and HTTP/3 (QUIC) listeners. See [HTTP/3](./docs/http3.md).
- WebSocket and other `Connection: Upgrade` requests are tunneled end-to-end.
- TCP, TLS (by server name, without termination) and UDP stream listeners. See [Stream Listeners](./docs/configuring.md#stream-listeners).
- Per-backend NCSA access and error logging, a top-level `access_log`, and logging to stdout or stderr. See [Access Logs](./docs/access-logs.md).
- Loading multiple config files from a subdirectory, and automatic config reload when files change. See [Automatic Config Reload](./docs/configuring.md#automatic-config-reload).
- In-place TLS certificate rotation, the `tls_runtime_certs` listener option, and a certificate inventory at `/trickster/certificates`. See [TLS](./docs/tls.md).
- Readiness endpoint `/trickster/ready`, plus `mgmt.shutdown_delay` and `mgmt.shutdown_drain_timeout` for graceful drains. See [Graceful Shutdown and Readiness](./docs/configuring.md#graceful-shutdown-and-readiness).
- PROXY protocol support and the `trusted_proxies` listener option. See [Trusted Proxies](./docs/configuring.md#trusted-proxies).
- Cache operation duration metrics ([#949](https://github.com/trickstercache/trickster/pull/949)).

### Changed

- Responses of unknown length and Server-Sent Events streams are flushed as bytes arrive, and HTTP trailers are passed through.
- ClickHouse SQL parsing uses AfterShip's ClickHouse parser ([#1099](https://github.com/trickstercache/trickster/pull/1099)).
- Improved RFC conformance of the object cache ([#1137](https://github.com/trickstercache/trickster/pull/1137)).

### Fixed

- Fast-forward evaluation time is taken from the range end ([#1101](https://github.com/trickstercache/trickster/pull/1101)).
- MySQL `NO_BACKSLASH_ESCAPES` comments are honored ([#1111](https://github.com/trickstercache/trickster/pull/1111)).
- ClickHouse delta proxy cache fixes ([#1125](https://github.com/trickstercache/trickster/pull/1125)).
- TSM parses PromQL with extraneous parentheses ([#1134](https://github.com/trickstercache/trickster/pull/1134)) and handles vector-to-scalar expressions ([#1141](https://github.com/trickstercache/trickster/pull/1141)).

## [2.0.0] - 2026-02-10

Trickster 2.0 is a near-complete rewrite with performance, durability and extensibility in mind.
See [What's New in Trickster 2.0](./docs/new-changed-2.0.md) for an overview.

### Added

- Application Load Balancer backend provider with time series merge, first response, newest `Last-Modified`, user router and round robin mechanisms. See [Application Load Balancer](./docs/alb.md).
- Automated health check polling for any backend and a global health status endpoint. See [Health Checks](./docs/health.md).
- Cache object chunking for time series and byte ranges. See [Chunked Caching](./docs/chunked_caching.md).
- Time series backend request sharding. See [Time Series Sharding](./docs/timeseries_sharding.md).
- Authenticators for Basic Auth and ClickHouse Auth. See [Authenticator](./docs/authenticator.md).
- `rmatch` regular expression operations in the rules engine. See [Rules Engine](./docs/rule.md).
- Chainable request rewriters. See [Request Rewriters](./docs/request_rewriters.md).
- Cache purging by key or path. See [Caches](./docs/caches.md).
- Simulated latency. See [Simulated Latency](./docs/simulated-latency.md).
- InfluxDB 2.0 and Flux support. See [InfluxDB](./docs/influxdb.md).
- Environment variable substitution in sensitive configuration fields. See [Configuring Secrets](./docs/configuring.md#configuring-secrets-or-sensitive-information).
- Request body size limit for `POST`, `PUT` and `PATCH`, defaulting to 10MB. See [Request Body Handling](./docs/body.md).
- Brotli and Zstd compression.
- Images published to `ghcr.io/trickstercache/trickster`, and `trickstercache/trickster:main` on every merge to `main`.

### Changed

- **Breaking:** configuration is YAML instead of TOML.
- A common internal time series format replaces per-provider delta and merge algorithms.
- A new HTTP request router, up to 10x faster than the previous one.
- SQL-based backends use a lexer/parser instead of regular expressions.
- Packages are reorganized to be importable by other projects.
- Example configurations and the Docker Compose demo moved to [examples](./examples).
- The `vendor` directory is no longer committed; release source tarballs still include it.
- Docker images are published from this repository only, under `trickstercache`.

### Removed

- **Breaking:** Zipkin trace export, following its deprecation in OpenTelemetry. OTLP remains.
- Image publishing to the legacy `tricksterio` and `tricksterproxy` Docker Hub organizations.

### Fixed

- Nearly 100 race conditions and random panics.
